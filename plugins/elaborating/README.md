# elaborat.ing

Write notes, make drawings and diagrams, and work through comments in
[elaborat.ing](https://elaborat.ing), an open source workspace for documents
and diagrams. This plugin combines its remote MCP connector with skills for
MDX notes, Excalidraw drawings, D2 diagrams and review comments.

## Connect your account

Create an elaborat.ing account, then connect the plugin's elaborat.ing
connector and sign in when prompted. It connects to
`https://elaborat.ing/mcp` over HTTPS using OAuth. The connector acts with your
account's permissions and can only access projects you can open.

## What you can ask for

- Read and search your projects and notes.
- Write or edit Markdown and MDX notes with embedded drawings and diagrams.
- Create drawings and D2 diagrams, and show files in the chat.
- Work through comments marked **Ask an agent**, make the requested changes
  and reply in their threads.

For example: "Work through the open comments in my elaborat.ing project."
Or: "Sketch this idea as a drawing in elaborat.ing and show it to me."

Agents can archive projects. Permanent deletion is available only to a
person in the elaborat.ing app.

If the Projects panel cannot open in your chat, choose **Open in elaborat.ing**
to continue in the app.

## Data and privacy

The plugin sends the tool arguments needed for your request to elaborat.ing
and returns the relevant project files, search results and comments to your
assistant. Requested changes are saved to your elaborat.ing account. The
plugin contains instructions and a remote connector configuration; it does
not install a local server or run lifecycle hooks.

Read our [privacy policy](https://elaborat.ing/privacy) and
[terms of service](https://elaborat.ing/terms). For setup and usage, see the
[project documentation](https://github.com/meech-ward/elaborat.ing#connect-an-agent).
For help, visit [support](https://elaborat.ing/support).
